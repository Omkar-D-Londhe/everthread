## 8. Antigravity asset-import protocol
1. Read this file and `02a_ASSET_REGISTRY.csv`; do not read the stale manifest in the ZIP.
2. Unpack the ZIP outside the repository. List the files and compare with the registry; any extra/missing file ⇒ stop and report.
3. Re-measure dimensions, mode and SHA-256; mismatch with the registry ⇒ stop.
